# Scripts

Utility scripts for the project.

## generate-images.mjs

Generates `og-image.png` (1200×630) and `favicon.ico` (32×32) from SVG sources.

```bash
npm run generate:images
```

Run after changing `public/icon.svg` or `public/og-image.svg` to regenerate assets.
